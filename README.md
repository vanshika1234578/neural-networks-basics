# Neural Networks Basics

A hands-on learning project exploring neural networks using Python and TensorFlow/Keras.

## Project Objective
Build a simple binary classification model to predict whether a plant needs water based on:
- Soil moisture
- Temperature
- Sunlight hours

## Concepts Covered
- Data preprocessing with Pandas
- Feature scaling using Min-Max normalization
- Training and testing data split
- Neural network architecture
- Dense layers
- ReLU and Sigmoid activation functions
- Binary Cross-Entropy loss
- Stochastic Gradient Descent (SGD)
- SGD with Momentum
- Adagrad optimizer

## Model Architecture
- Input layer: 3 features
- Hidden layer: 8 neurons (ReLU)
- Output layer: 1 neuron (Sigmoid)

## Tech Stack
- Python
- NumPy
- Pandas
- Scikit-learn
- TensorFlow
- Keras
- Jupyter Notebook

## Getting Started

Install dependencies:

pip install -r requirements.txt

Launch Jupyter:

jupyter notebook

Open neural_networks_basic.ipynb.

## Dataset
The notebook uses 16 illustrative samples created directly in code. This is an educational experiment, not a production-ready prediction model.
